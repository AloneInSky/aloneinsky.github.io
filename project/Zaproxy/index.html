ZAP Proxy Report Aggregator with PDF Export

This project uses ZAP Proxy running as a daemon on a cloud server to collect web application security data.

Each scan generates multiple reports (e.g., one per link), which are then processed and aggregated using Pandas into a single, consolidated report that summarizes key information—such as the number of POST and GET requests per endpoint. The final results are stored in a database and exported as PDF reports for easy review.

This project demonstrates my ability to work with API daemons, process and merge complex datasets, and generate automated, shareable reports, highlighting skills in cloud deployment, data pipelines, and report automation.
